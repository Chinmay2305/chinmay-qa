## Chinmay Agrawal — QA Portfolio

A responsive, dark-themed portfolio built with plain HTML, CSS, and JavaScript. No build tools or frameworks are required.

## Files

- `index.html` — page content and links
- `styles.css` — layout, colors, responsive styling
- `script.js` — mobile navigation and small link reminders
- `assets/` — place your résumé PDF and optional images here

## Run locally

1. Extract the ZIP.
2. Open the `chinmay-qa-portfolio` folder.
3. Double-click `index.html` to preview in your browser, or open the folder in VS Code and use the Live Server extension.

## Personalize before publishing

Search `index.html` for the following and replace them:

- `Chinmay Agrawal` if you want a different display name
- Generic LinkedIn and GitHub URLs
- `replace-with-your-email@example.com`
- `assets/Chinmay-Agrawal-Resume.pdf` with your actual résumé PDF
- Experience timeline placeholders with verified employer names, job titles, dates, and responsibilities
- Project links (`https://github.com/`) with real repositories or case studies

The project cards are starter case-study prompts and illustrative visuals. Do not describe them as completed work until you add your own evidence and confirm the claims are accurate. Keep confidential employer/client information out of public repositories.

## Deploy free with GitHub Pages

1. Create/sign in to GitHub and create a **public** repository named `chinmay-qa-portfolio`.
2. Upload the contents of this folder to the repository root. `index.html`, `styles.css`, and `script.js` should be at the top level, not nested in an extra folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for deployment. Your site should be available at `https://YOUR-USERNAME.github.io/chinmay-qa-portfolio/`.
6. Every push to the selected branch updates the site.

## Deploy free with Vercel

1. Push this folder to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. For this static HTML site, leave the framework preset as **Other** and do not configure a build command. Set the output directory to `.` if Vercel asks for one.
5. Deploy. Vercel will provide a public URL; future pushes can trigger deployments.

Check the current free-plan terms of each host before publishing. A custom domain is optional and costs extra.
